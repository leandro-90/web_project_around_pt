# 🗺️ Around The U.S. (Web Project Around PT)

Uma aplicação web interativa e responsiva que permite aos usuários compartilhar fotos de locais nos Estados Unidos, curtir postagens e editar as informações de seu próprio perfil.

🔗 **Acesse o site:** [leandro-90.github.io/web_project_around_pt](https://leandro-90.github.io/web_project_around_pt/)

---

## 📌 Sobre o Projeto

O **Around The U.S.** é uma página social interativa desenvolvida para praticar manipulação do DOM, eventos em JavaScript e estruturação de layouts modernos. O projeto foca em oferecer uma experiência dinâmica, permitindo interação em tempo real com os elementos da página através de modais de formulário.

### 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica e acessível.
- **CSS3:** Metodologia BEM (Block Element Modifier), Grid Layout, Flexbox e media queries para responsividade.
- **JavaScript (ES6+):** Manipulação dinâmica de elementos, eventos de formulário, abertura/fechamento de modais e interações de curtir/excluir cards.

---

## 🎨 Funcionalidades

- **Edição de Perfil:** Alteração do nome e da ocupação do usuário via formulário em modal.
- **Adição de Cards:** Inserção de novos locais com título e URL de imagem customizados.
- **Interatividade:**
  - Botão de "curtir" (like) nos cards.
  - Removido/exclusão de cards da galeria.
  - Visualização de imagens em tamanho expandido ao clicar no card.
- **Design Responsivo:** Interface otimizada para dispositivos móveis, tablets e desktops.
